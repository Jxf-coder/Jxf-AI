# 爆款短视频文案实战方法论

来源编号：SRC-SHORTVIDEO-METHOD

这是按原文章节重排的全文，不是摘要。人名已替换。进店数、获客数、日销和「市场验证」是讲师口述，待核验，不构成承诺。疗效句、评论扣数字、私信领资料、假装删除，标了不得执行，公式本身保留。

## 前言

这套文案分三段：开头抓留存，正文做内容，结尾做转化。原文用三个指标描述：前 2 秒留人，前 5 秒还在看，片尾只做一件转化。适用短视频口播、实体拓客、知识科普、好物分享、技能分享。结构可以套用，事实不能编。

## 第一章 七类开头

开头要抓住一个情绪，让人停下划屏。七种开头对七种需求。每一种都有公式、案例位置、赛道和优化要点。

### 1. 好奇

抛出没体验过、难实现的场景。

公式：

1. 某事是一种什么体验？
2. 如何不做某事也能达成某结果？
3. 如果做了某事，生活会发生什么变化？
4. 为什么有的人做了某事，结果却相反？

赛道：科普、生活、副业、养生。

要点：用能核对的具体事实，不空问。原文例句里的「吃素十年身体会怎样」「月薪 3000 如何住别墅」只说明要具体，不能当成真事。

### 2. 借势

绑已公开的话题、作品或行业讨论，让内容自带语境。必须和热点有关，不能硬蹭。

公式：

1. 曾经被公开讨论的某物，现在怎么样了？
2. 某热门作品里，我只关注隐藏的某点。
3. 很多人在用的某物，实测怎样。

赛道：好物、书单、家居、美妆。

要点：不点名真人当证据，不写「明星都在用」。

### 3. 痛点

打中日常的一个烦恼。越准，关注的人越垂直。

公式：

1. 明明某条件，为什么偏偏某结果？
2. 不懂某事的人，要补上某点。
3. 某行业的新规则，你还不知道？

赛道：职场、母婴、实体门店、情感。

要点：一个人群，一个痛点。不写所有人都适用的空泛烦恼。

### 4. 极限或冷知识

用极值或小众事实打断习惯性划屏。

公式：

1. 某个范围内公认靠前的某物。
2. 想做好某事，务必记住某点。
3. 多数人不清楚的一个事实。

赛道：房产、美食、干货、本地生活。

要点：数字有来源。不用「最、第一、顶级、99% 都错」。原文「喝水方式全错才最解渴」「富人小区在这里」是极限词例句，不照抄。

### 5. 风险提醒

点出错误做法可能带来的问题，让人留下来找办法。

公式：

1. 提醒不要随意做某事。
2. 再不改掉某习惯，后面会遇到某问题。
3. 某行业规则在变，从业者要先弄清变化。

赛道：健康、理财、居家。

要点：讲得清的风险。不恐吓，不夸大。原文「不要凌晨独自外出」「长期熬夜会出现多种问题」只说明风险提醒的形状，不写成医学结论。

### 6. 认知反差

打破一个常见看法。反差必须符合事实。

公式：

1. 人人知道某事，却漏了关键的某点。
2. 我能做到某事，唯独搞不定某点。
3. 只用低成本的某做法，就能解决某问题。

赛道：减脂、副业、养生、育儿。

> 不得执行：天天躺着就有收入；只吃饭不运动也能瘦。这是原文例句，和事实相反，不采用。

### 7. 即时利益

开头就说一个能落地的好处。原文把这一类当成转化最高的开头。

公式：

1. 没想到靠某做法，解决了多年的某问题。
2. 有了某工具，就不用再应付某麻烦。

赛道：实体店、养生、技能教学。

要点：好处具体，有条件和周期。

> 不得执行：一套睡觉调理法治好多年颈椎病。没有诊疗依据，不写。

## 第二章 八种正文

八套都给出顺序、作用和适用。示例里的人数和金额是口述，不能写成这家的结果。带「私信」的收尾见第三章，不得执行。

### 结构 1 通用

钩子 → 塑造期待 → 分步方案 → 一种结尾。

作用：降低跳出，撑过前 5 秒，最后只做一件事。全品类优先。

示例形状：先问一个具体问题，再承诺讲清几个方法，然后分步写做法，最后用一种允许的结尾。原文「单日进店 300+」「有难题可私信」不采用。

### 结构 2 实体门店

现象 → 危害 → 根源 → 解法。

作用：从问题拆进去，让人感到能用。适合美业、养生、餐饮。

示例形状：成交或复购困难 → 只靠低价就没有利润 → 缺的是某套可执行的说法 → 写出那几步。不把「4 套话术」写成已有的内部资料。

### 结构 3 人设

利益开头 → 可核对的经历 → 分步方案 → 一种结尾。

作用：利益抓人，经历建立信任。适合行业分享、知识账号。

没有证据不写「深耕十余年」「单日获客 300」。不写「私信领取全套话术」。

### 结构 4 可复制的做法

成果前置 → 说明别人能照步骤做 → 分步实操 → 一种结尾。

作用：先给结果，再给步骤。适合技能和方法教学。

成果必须已核对。不写「今天爆单」「私信领完整脚本」。

### 结构 5 观点

金句和论据循环，一层比一层具体。适合观点口播、财经、职场。

原文示例的逻辑是：获客是第一要务，因为没有客源则产品再好也空；线下流量在变，所以要有能持续获客的方法。不写「终将被淘汰」这种绝对判断，除非有已核对的事实。

### 结构 6 行业做法

揭秘一种做法 → 写清条件和边界 → 落地步骤。

适合垂直干货。

> 不得执行：落地后门店永久不愁客源。

### 结构 7 招商或门店

一个利益 → 已授权案例 → 实操步骤 → 一种结尾。

没有授权和来源，不能写「多家日销破万都在用」。不写「完整资料私信领取」。

### 结构 8 科普或创业

观点 → 真实经过 → 专业拆解 → 总结。

原文形状：不到最后不放弃 → 大客户多次拒绝 → 不硬推，靠把价值说清再创造机会 → 后来签成。经过必须真实。

备用纪实顺序：事实 → 感受 → 隐藏问题 → 观点 → 案例 → 总结。适合生活化、纪实。

## 第三章 五种结尾

结尾决定互动、主页访问、关注和是否违规。一条只用一种。

### 1. 评论互动

> 不得执行：评论 666，全套资料免费发你。

原文说这样做是为了拉高评论、筛出想要的人。允许的改法是原文自己写的替换：让人回复想看的主题，例如「想要回复干货」。不发联系方式，不承诺私发资料。

### 2. 主页引导

完整方法放在主页另一条，最好是置顶。可以执行。作用是让人看主页，增加账号整体播放。

### 3. 关注

说清关注后能持续看到什么，例如每天一条可操作的做法。可以执行。不写关注才给福利。

### 4. 私信领资料

> 不得执行：私信 666，领取全套内部资料。也不把人导到微信。

### 5. 假装删除

> 不得执行：本条即将删除，建议点赞收藏。

## 附录三条

1. 开头可以混搭，优先「痛点 + 利益」。
2. 正文结构固定后，只替换行业词，批量写同一系列。事实和合规边界不替换。
3. 结尾不要混用。一条只有一种转化。
