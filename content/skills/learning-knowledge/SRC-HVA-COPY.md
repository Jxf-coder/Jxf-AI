## 一、你必须掌握的H-V-A三段式获客公式
所有获客短文案都由三个部分组成,缺一不可:
H = Hook(钩子)—— 让人停下来
功能:前2秒抓住注意力,打破刷视频的惯性。 时长占比:2秒(约10-15字)
Hook的6种类型(每次创作选择最适合的1种):
反常识型——打破人们对某件事情的固有认知 例:“你敢信吗?净水器根本不用花钱买” / “别再花几千块买净水器了,真的没必要”
痛点唤醒型——直接戳中目标人群的核心烦恼 例:“还在每天下楼扛桶装水的邻居注意了” / “熬夜掉发真的烦,发缝越来越宽”
场景切入型——用特定人群/地域/场景建立亲近感 例:“所在城市的家人们,净水机免费入户了” / “各位邻居注意了”
欲擒故造型——先否定再解释,制造悬念 例:“如果有人说完全免费,那肯定是骗人的。但是...”
数据冲击型——用具体数字制造冲击力 例:“80%的新客户都是老客户推荐来的” / “比桶装水省50%”
对比反转型——先描述常见做法,再颠覆它 例:“你绝对想不到,现在流行免费投放模式”
V = Value(价值)—— 让人信你
功能:用利益点堆叠+信任状,让用户觉得”划算、可信、想要”。 时长占比:5-6秒(约40-60字)
Value的三层堆叠结构:
第一层:核心利益点(不可抗拒的利益组合)
找到用户最敏感的3个利益点,用”免费/低价+高价值+零风险”的组合反复敲击。
利益点公式的三种变体: - 免费三连:A免费 + B免费 + C免费,每天低至X元 例:“机器免费,滤芯免费,售后全免费,每天低至几毛钱” - 省钱对比:比XX省X%,每天只花X元 例:“比桶装水新鲜,比买净水机划算,比小区售水机便宜一半” - 效果承诺:效果达到XX标准,价格只要XX 例:“过滤效果优于大部分5000元以上净水器,却不用你花钱买”
第二层:效果/体验描述(让用户能想象到使用后的场景)
用感官化语言描述使用体验,让用户产生画面感: - 口感/触感描述:“甘甜清爽,泡茶煮饭都香了” - 便捷感描述:“拧开水龙头就能直接喝,不用再出门打水” - 状态描述:“发根蓬松多了,发缝也不明显了”
第三层:信任状叠加(消除顾虑的3种武器)
至少包含以下1-2种信任元素:
A = Action(行动)—— 让人动起来
功能:明确的互动指令,触发平台算法推荐,同时收集用户信息。 时长占比:2-3秒(约15-25字)
Action的4种类型(每次创作选择最适合的1-2种):
评论互动型——引导用户在评论区扣数字/关键词 例:“评论区扣8优先安排” / “评论区扣666抢安装名额” / “评论区打安装我来联系你”
信息收集型——引导用户留下关键信息 例:“留下你的城市名,我统一安排” / “打出你的城市,我马上回复你”
到店引导型——引导用户到店体验 例:“想喝放心水的邻居,直接来我店铺登记安装” / “欢迎到店测口感”
紧迫感型——制造稀缺或限时感 例:“名额有限,优先安排” / “马上抢安装名额”

## 五、文案创作的10条铁律
口语化原则:像跟邻居聊天,不用书面语。“注意了”“真的”“你敢信吗”“居然”
短句原则:每句不超过15字,读起来不喘气。
重复原则:核心利益点至少重复2次,用不同方式表达。
数字原则:能用数字不用形容词。“省50%”比”省很多”有力100倍。
对比原则:永远绑定一个旧方案做对比,让用户感知到差异。
场景化原则:让用户能想象自己在用这个产品的画面。
零风险原则:文案中必须有消除顾虑的元素,让人敢行动。
指令明确原则:Action部分必须给一个具体的、低门槛的动作。
本地亲近原则:用地域词/人群词建立亲近感,降低广告抵触。
不讲废话原则:12秒内每1秒都要有信息量,删掉所有修饰性废话。
