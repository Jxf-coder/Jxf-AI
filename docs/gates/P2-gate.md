# P2 人工闸门（Hard Gate）

> 阶段：Phase 2 · 知识库（上传 → 解析 → 确认 → 提问 → 证据）
> 修订：2026-11-07（按当前知识库信息架构重写）
> 验收主体：用户本人；AI 自评不算通过

## 交付物

- 入库：`documents` / `ingest_files` / `document_chunks`；PDF / Word / Markdown 解析；扫描件 OCR 补录与自动 OCR 回落
- 检索：`pg_bigm` 关键词 + `pgvector` 向量双通道；无 embedding 时如实降级为纯关键词
- 知识卡：`knowledge_cards` + `kb_card_versions`；待确认 → 已确认门槛（`v_confirmable_cards`）；证据链 `kb_card_sources`
- 运营视图：知识卡 / 巡读上传 / 条目四字段 / 缺口 / 问答来源 / 回归题（Tab 由 URL 承载）
- 问答：`lib/knowledge/qa.ts`，引用编号必须真实存在；`qa_logs` 记录命中与无效引用
- 共享：卡片共享审批（部门→L1 审批→共享），跨部门只读
- 回收站：文档 / 卡片软删与恢复、彻底删除
- 页面：`/knowledge`（六个 Tab）、`/knowledge/cards`
- 测试：`test:knowledge`、`test:rls`（知识库段）

## 验收步骤（可照着点的路径）

> 入口：`http://127.0.0.1`；账号 `admin@jxf.local`，口令见 `.env` 的 `SEED_PASSWORD`。

### A. 入库与解析

- [ ] 1. `/knowledge` → 「巡读上传」：上传一份 PDF，进度正常推进，完成后出现在目录树
- [ ] 2. 打开文档详情：能看到页数、切片数与解析状态；扫描件显示「待 OCR」并支持人工补录
- [ ] 3. 上传重复文件（同部门同 sha256）被拒绝；换部门上传同名内容允许

### B. 知识卡与确认门槛

- [ ] 4. 「知识卡」Tab：新建卡片，未挂证据时为 pending，不能直接确认
- [ ] 5. 从文档切片挂证据（引文必须能在原文逐字命中），卡片变为可确认
- [ ] 6. 确认后：卡片从待确认列表消失，状态为 confirmed，版本号推进
- [ ] 7. 冲突 / 过期 / 人工编辑过的卡片按视图规则显示，不能误确认

### C. 检索与问答

- [ ] 8. 「问答来源」Tab 提问：返回答案时引用编号可点击定位到文档页码与原文
- [ ] 9. 无相关依据时如实回答未命中，并沉淀到「缺口」Tab
- [ ] 10. 「回归题」Tab：基于已确认卡生成基线题并运行，保留率与失败题可见

### D. 隔离与共享

- [ ] 11. 用 L3 账号登录：看不到兄弟部门文档与卡片；搜索只返回本部门结果
- [ ] 12. L2 申请卡片共享 → L1 在 `/me/approvals` 通过 → 兄弟部门可读但不可改
- [ ] 13. 收回共享后兄弟部门立即不可见

### E. 回收站

- [ ] 14. 文档软删后进入 `99-回收站`，关键词召回不再命中；恢复后重新命中
- [ ] 15. 彻底删除文档 / 清空回收站后，数据库行与切片一并消失
